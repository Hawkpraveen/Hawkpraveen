## 🚀 Featured Project: ResearchPilot

**ResearchPilot — AI Research & Decision Agent** *(Independent project · In development)*

ResearchPilot is being designed to help users investigate complex questions, collect evidence from multiple sources, verify important claims, compare options, and produce structured reports with citations.

### The problem

Researching a decision often means opening many pages, comparing inconsistent information, checking sources manually, and assembling findings into a report. ResearchPilot aims to make that process more systematic and auditable.

### Planned capabilities

- 🧭 **Research planning:** Break a broad research goal into focused questions and subtasks.
- 🔎 **Web research:** Search public sources and retrieve relevant information.
- 🧾 **Evidence records:** Preserve claims, source URLs, excerpts, and retrieval timestamps.
- 🔍 **Verification:** Identify missing information, unsupported claims, and conflicting evidence.
- ⚖️ **Comparison:** Evaluate alternatives against explicit user-defined criteria.
- 📑 **Decision-ready reports:** Generate summaries, comparison tables, citations, risks, and uncertainties.
- 🛡️ **Bounded workflows:** Apply limits to retries, research rounds, execution time, and model usage.
- 📊 **Evaluation:** Test output quality, evidence coverage, latency, and cost.

### Planned architecture

| Component | Technology |
|---|---|
| Frontend | React, TypeScript, Vite |
| Backend API | Node.js, Express, TypeScript |
| AI agent service | Python, FastAPI, LangGraph |
| Persistence | MongoDB |
| Local model experimentation | Ollama |
| Workflow approach | Evidence-first research, bounded loops, and explicit validation |

The project uses three separate repositories: `researchpilot-web`, `researchpilot-api`, and `researchpilot-agent`.

> **Status note:** ResearchPilot is under development. The capabilities above describe the intended product, not a claim that every feature is already implemented or deployed.
